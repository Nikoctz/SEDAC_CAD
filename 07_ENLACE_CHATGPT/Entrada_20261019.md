3. Sensibilidad del margen estructural 2,247 frente a 2,20

[hecho] El paquete identifica un margen analítico mínimo de 2,247, un umbral interno de 2,20, un reparto de carga 70/30 y una excentricidad de 107,5 mm. Las dos últimas entradas son hipótesis no medidas. Fuente: ESTADO_ACTUAL.md y preguntas de la sección 6. PAQUETE_CHATGPT.md

3.1 Cuánto margen existe realmente

[calculo] Diferencia absoluta:

    Δn = 2,247 − 2,20 = 0,047

[supuesto] Para un mismo modo de falla, se considera que el margen n es inversamente proporcional a la demanda mecánica D, manteniendo constante la capacidad admisible.

    n = C / D

[calculo] El incremento relativo de demanda que llevaría exactamente al umbral es:

    ΔD/D₀ = 2,247/2,20 − 1 = 2,136 %

[calculo] Sensibilidad ilustrativa del margen ante mayor demanda

    (gráfico de barras; el texto pegado perdió el formato)
    Margen analítico / umbral 2,20 — valores leídos: 2,14 · 2,17 · 2,22 · 2,23 · 2,26
    Incrementos: 0 % · 1 % · 2 % · 2,14 % · 3 % · 4 %

Modelo inversamente proporcional: n = 2,247 / (1 + incremento/100). No representa una simulación estructural de SEDAC.

[hipotesis] Este resultado indica que conviene comprobar la sensibilidad antes de declarar robusto el margen. No demuestra que el diseño vaya a fallar al aumentar una carga un 2,14 %.

3.2 Dos sensibilidades especialmente importantes

A. Reparto de carga 70/30

[supuesto] Si el elemento que gobierna recibe el 70 % de una carga total y su solicitación es lineal con esa fracción:

    n(p) = 2,247 · 0,70 / p

[calculo] La fracción que llevaría el margen al umbral es:

    p_crit = 2,247 · 0,70 / 2,20 = 0,71495

[calculo] En ese caso ilustrativo, cambiar de 70/30 a aproximadamente 71,5/28,5 bastaría para alcanzar 2,20.

[hipotesis] Este resultado solo es aplicable si el caso crítico depende directamente de esa fracción de carga. Pendiente: identificar el elemento y el modo de falla que gobiernan.

B. Excentricidad de 107,5 mm

[supuesto] Para un caso dominado exclusivamente por flexión, con momento M = F·e:

    n(e) = 2,247 · 107,5 / e

[calculo] La excentricidad que llevaría al umbral sería:

    e_crit = 2,247 · 107,5 / 2,20 = 109,80 mm

[calculo] La diferencia respecto a 107,5 mm es aproximadamente 2,30 mm.

[hipotesis] Si el caso crítico combina flexión, esfuerzos directos u otros efectos, esta expresión deja de representar la respuesta completa.
