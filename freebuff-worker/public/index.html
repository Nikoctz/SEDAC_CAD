SEDAC CAD MCP Bridge

Puente entre Freebuff y los MCP locales de Inventor y Revit.

Endpoints disponibles

Inventor

GET /inventor/tools - Listar herramientas

POST /inventor/call - Ejecutar herramienta

Revit

GET /revit/tools - Listar herramientas

POST /revit/call - Ejecutar herramienta

Estado

El Worker está desplegado pero los puentes locales necesitan:

  1. Los puentes HTTP corriendo en localhost:8766 (Inventor) y 8767 (Revit)
  2. Túneles (cloudflared/ngrok) exponiendo esos puertos
  3. Secrets configurados con las URLs de los túneles
